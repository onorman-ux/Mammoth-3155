### Online Restaurant Ordering System API!!

The Online Restaurant Ordering System is a FastAPI application that allows customers to browse restaurant menu items, place orders, make payments, use promo codes, track orders, and submit reviews.

Restaurant staff can manage menu items, ingredients, recipes, orders, promotions, payments, and customer reviews. Staff can also view reports related to revenue, menu popularity, and customer complaints.

This project was created for the Software Engineering ITSC-3155 Final Project.

## Project Features:

### Customer Features:

- Browse restaurant menu items
- Search menu items by name or food category
- Place an order (no account needed)
- Choose takeout or delivery
- Provide a delivery address
- Apply a promo code
- Pay for your order
- Track an order using a tracking number
- Rate and review an order

### Restaurant Staff Features

- Create, read, update, and delete menu items
- Manage restaurant ingredients and inventory
- Create recipes connecting menu items to ingredients
- Detect insufficient ingredients during checkout
- View all orders
- View one specific order
- View orders within a date range
- Update order statuses
- Create and manage promo codes
- Set expiration dates for promo codes
- View customer reviews and complaints
- View daily revenue
- View menu item popularity
